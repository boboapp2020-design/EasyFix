👤 สำหรับพนักงาน USER

แจ้งซ่อม ติดตามสถานะ และประเมินงาน

  1. ติดตั้งลงมือถือ (ครั้งแรก)เปิดลิงก์ด้วย Chrome → เมนู ⋮ → "เพิ่มไปยังหน้าจอโฮม" → ได้ไอคอน Easy Fix เหมือนแอป
  2. เข้าสู่ระบบกรอก รหัสพนักงาน + PIN 1234 (เปลี่ยน PIN ส่วนตัวได้ที่เมนู ☰ มุมขวาบน)
  3. แจ้งซ่อมแตะ "➕ แจ้งซ่อมใหม่" → เลือกหมวดงาน → แตะอาการที่พบ (เลือกได้หลายข้อ) → เลือกความเร่งด่วน → ใส่เบอร์โทร → แนบรูป (ถ้ามี) → ส่ง
  4. ติดตามสถานะแท็บ "📋 งานซ่อม" — มีจุดแดง ● = มีอัปเดตใหม่ แตะดูรายละเอียด ความคืบหน้า % และประวัติการดำเนินงาน
  5. ตรวจรับงาน + ให้คะแนนเมื่อสถานะเป็น "รอตรวจรับ" → ตรวจงานจริง → กด "👍 รับงาน" → ให้ดาว ⭐ 1-5
แจ้งซ่อม → รอตรวจสอบ → รับเรื่องแล้ว → กำลังดำเนินการ → รอตรวจรับ → กดรับงาน → ให้ดาว → เสร็จสมบูรณ์
🔒 ลืม PIN / เข้าไม่ได้ → แตะแบนเนอร์ "ลืม PIN" ในหน้าแรก เพื่อทัก LINE (soulina33) หรือโทร 020-917-35976

🛠️ สำหรับผู้ดูแลงานซ่อม ADMIN

เข้าด้วยรหัสแอดมิน (เช่น admin01) — ระบบพาเข้าโหมดผู้ดูแลอัตโนมัติ

  1. รับเรื่องงานใหม่หน้า "📊 ภาพรวม" เห็นงานรอตรวจสอบ → แตะใบงาน → ระบุระยะเวลา + รายละเอียด → "✅ รับเรื่อง" (หรือ "⛔ ดำเนินการไม่ได้" พร้อมเหตุผล)
  2. อัปเดตความคืบหน้าเลื่อนแถบ % + บันทึกสิ่งที่ทำ → ผู้แจ้งเห็นทันที ระบบเก็บประวัติทุกครั้ง
  3. ปิดงานซ่อมเสร็จ → "🏁 ปิดงาน" → ระบบแจ้งผู้แจ้งให้ตรวจรับและให้คะแนน
  4. จัดการพนักงานแท็บ "👥 พนักงาน" → ค้นหาด้วยรหัส/ชื่อ → แก้ไขข้อมูล·ย้ายห้อง / เพิ่มพนักงานใหม่ / ลบ / รีเซ็ต PIN เป็น 1234 / ตั้ง 🔒 หมวดที่ห้ามแจ้ง — มีผลทันที
  5. ดูสถิติ + ส่งออกรายงานหน้า "ภาพรวม" ล่างสุด: กราฟตามสถานะ/หมวด/ความเร่งด่วน + ปุ่ม "📥 ส่งออกเป็น Excel"
