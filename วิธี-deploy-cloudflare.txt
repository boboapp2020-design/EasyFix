  Easy Fix — วิธี Deploy ขึ้น Cloudflare Pages
  (ลากไฟล์ ไม่ต้องต่อ GitHub / ไม่ต้องใช้ CLI)
═══════════════════════════════════════════════

สิ่งที่ต้องมี: บัญชี Cloudflare (สมัครฟรีที่ dash.cloudflare.com)

──────────── ขั้นตอน ────────────

1) เข้า https://dash.cloudflare.com  → เมนูซ้าย "Workers & Pages"

2) กด  Create  →  แท็บ  "Pages"  →  "Upload assets"
   (หัวข้ออาจเขียนว่า "Deploy a site" / "Direct Upload")

3) ตั้งชื่อโปรเจกต์ เช่น  easyfix  →  กด Create project

4) ลากทั้งหมด "ภายในโฟลเดอร์ deploy-cloudflare" เข้าไปวาง
   ⚠️ สำคัญ: ลากเฉพาะ "ไฟล์ข้างใน" (index.html, cat, รูป ฯลฯ)
      ไม่ใช่ลากตัวโฟลเดอร์ deploy-cloudflare เข้าไป
   หรือจะลากไฟล์ EasyFix-cloudflare.zip เข้าไปก็ได้ (Cloudflare แตก zip ให้เอง)

5) กด  Deploy site  → รอสักครู่ → ได้ลิงก์:
       https://easyfix.pages.dev   (แอปพนักงาน)
       https://easyfix.pages.dev/manual.html   (คู่มือ)

──────────── เสร็จแล้ว ────────────
• พนักงานเปิดลิงก์ → login รหัสพนักงาน + PIN 1234
• เพิ่มไปหน้าจอโฮมได้เหมือนเดิม
• ข้อมูลยังผูก Google Sheets เดิมทุกอย่าง (ไม่ต้องตั้งค่าใหม่)

──────────── อัปเดตแอปครั้งต่อไป ────────────
เข้าโปรเจกต์ easyfix → Create deployment → ลากไฟล์ชุดใหม่ทับ → Deploy
(ลิงก์ .pages.dev เดิมไม่เปลี่ยน)

* ไฟล์นี้ลบทิ้งได้ ไม่กระทบการทำงาน *
